# Change log

Each version of the rubric is listed here with what changed. Versions are numbered so that a citation points to a fixed text.

## 0.1 · October 2026

First public version. Preliminary.

- 33 criteria in four categories: Elicit (12), Re-tell (7), Interpret (9), Retain (5).
- Each criterion carries a descriptor, a descriptive prompt ("How does the agent ..."), a binary prompt ("Does the agent ..."), and anchors to the OHA statements, the NCHS Historical Thinking Standards, and the AHA History Discipline Core.
- Criterion numbers use the prefixes E (Elicit), R (Re-tell), T (Interpret), and K (Retain).
- Published with the Critical Reflection "Can Oral History and Auto-autobiography Have a Candid Conversation?", the project abstract, and the research question slides.
